1. Чистый код
   Модуль = пара `.h` + `.c`, одна ответственность.
   Непрозрачные типы: `typedef struct HashMap HashMap;`, структура определена в `.c`.
   Имена: функции `snake_case` с префиксом модуля (`hashmap_put`), типы `PascalCase`, константы `UPPER_CASE`. Без `p`, `tmp`, `d`.
   Функция ≤ \~30 строк, вложенность ≤ 3, ранние возвраты.
   Ошибки через `enum` статус + out-параметр; результаты `malloc`/`fopen`/`read` проверяются всегда.
   Владение памятью описано в комментариях API; `create` ↔️ `destroy`; `destroy(NULL)` безопасен.
   `const` везде, где возможно.
   Без глобального состояния и магических чисел.
   Не-публичное — `static`.
   Комментарии объясняют «почему», а не «что».
   `clang-format` + `clang-tidy`.
2. Git
   **Ветки:**
   `main` — только релизы с тегами
   `develop` — интеграция
   `feature/<name>` — от `develop`, merge `--no-ff`
   `fix/<name>` — баги
   `release/x.y.z` — подготовка релиза
   **Коммиты** (Conventional Commits): `<type>(<scope>): <повелительное наклонение>`
   Типы: `feat fix refactor test docs build chore style`.
   Один коммит — одно изменение, сборка проходит на каждом коммите.
